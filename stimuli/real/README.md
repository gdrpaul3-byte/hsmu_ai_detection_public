# Real Portrait Stimuli

The images in this directory are derived from the Flickr-Faces-HQ (FFHQ) dataset (Karras et al., 2019). Each image was aligned and cropped as provided by FFHQ, with a white square box added at the lower right and resized for experiment/repository use.
